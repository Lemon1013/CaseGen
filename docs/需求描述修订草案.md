# 六模块需求描述（精简版）

日期：2026-10-20（北京时间）。在旧版"只有章节名"和上一版"过细"之间取中间值：**每章 2~3 句，点出业务对象和关注维度，不列具体分支、不给数值。**

## 一、集合竞价撮合成交（AUC）

```
业务范围：集合竞价撮合成交。
关注成交价格的确定规则，以及价格优先、时间优先在撮合中的体现，覆盖不同候选价位数量与剩余量情况下的组合。
```

## 二、单笔成交金额（AMT）

```
业务范围：单笔成交金额。
关注单笔金额的计算口径（成交价格与成交数量的关系），以及价格位数、小数边界、数量类别等条件组合。
```

## 三、累计成交金额（ACC）

```
业务范围：累计成交金额。
关注多笔单笔金额累加的形成过程，以及金额精度、尾数边界和累加范围。
```

## 四、开盘价（OPN）

```
业务范围：开盘价。
关注开盘价的产生方式与确定依据，以及不同申报分布、无成交、除权除息等情形下的处理。
```

## 五、收盘价（CLS）

```
业务范围：收盘价。
关注收盘价的产生方式，以及不同成交分布、精度尾数、无成交和停牌情形下的处理。
```

## 六、撤单订单类型验证（CAN）

```
业务范围：撤单订单类型验证。
关注不同订单类型（如限价单、市价单）在各订单状态下发起撤单的处理差异，以及撤单的时段限制与生效条件。
```

## 关键取舍

- **保留**："成交价格与成交数量的关系"、"价格位数、小数边界、数量类别"、"不同订单类型在各订单状态"——这些是测试维度，不是答案
- **去掉**：具体的小数位枚举（1/2/3位）、阈值分支（>5/=5/<5）、具体数值
- **撤单补充**：按确认加入"如限价单、市价单"作为方向提示。规则文档只区分限价/市价申报，不涉及本方最优、对手方最优、市转限、市转撤等细分类型（这些来自订单矩阵），因此只提示到限价/市价一级，不写完整枚举
