# Agent 会话功能介绍（单文件 HTML 演示文稿）

一句话说明：介绍 Agent 会话功能的三大重点能力、页面效果、已交付的用户管理 / 会话隔离成果与后续方向，离线双击 `index.html` 即可演示。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 自包含单文件 HTML 演示文稿，14 页，CSS / JS 全部内联，离线双击可用 |
| `assets/*.png` | 7 张页面功能截图，从 `docs/superpowers/plans/screenshots/` 原样复制（未修改原图） |
| `平台Agent会话.html` | 截图已内嵌的真·单文件版（约 2.1 MB），只拷这一个文件即可离线演示 |
| `README.md` | 本文件：打开方式、素材来源与演示数据声明 |

index.html 需与 assets/ 目录一起拷走；`平台Agent会话.html` 可单独使用，两者内容完全一致。

## 打开方式

- **最简单**：双击 `index.html`，用任意现代浏览器（Chrome / Edge / Firefox）打开即可，无需服务器、无需联网、无需额外安装。
- 也可在目录下启动本地静态文件服务后用浏览器访问 index.html（非必需）。

### 操作

| 操作 | 按键 / 方式 |
| --- | --- |
| 上一页 / 下一页 | `←` / `→`、`空格`、`PageUp` / `PageDown`、底部「上一页 / 下一页」按钮 |
| 点击翻页 | 点击页面左侧 26% 区域上一页、右侧 26% 区域下一页 |
| 首页 / 末页 | `Home` / `End`，或底部首末页按钮 |
| 目录跳转 | 第 3 页目录条目可点击跳转；底部「目录」按钮回到目录页 |
| 演讲者备注 | `N` 或底部「备注」按钮（默认隐藏，按页切换内容） |
| 全屏 | `F` 或底部「全屏」按钮（requestFullscreen） |
| 打印 / 导出 PDF | `P` 或底部「打印 / PDF」按钮；打印对话框选「另存为 PDF」，纸张横向并勾选「背景图形」 |
| 页码直达 / 刷新保持 | 地址栏 `#3` 直达第 3 页；URL hash 在刷新后保持当前页 |

- 画布为固定 1280×720（16:9），用 CSS `transform: scale()` 自适应视口并保持比例居中。
- `@media print` 下每页一张、隐藏导航控件、用 `print-color-adjust: exact` 保留深色背景。
- 全部状态由 URL hash 与内存保存；无自动播放、无外部网络请求。
