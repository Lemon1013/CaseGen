# 竞价交易系统需求说明（补充）

版本：v1.0
适用范围：证券竞价交易系统
文档性质：**系统需求说明**，描述交易系统在实现交易所业务规则时所需的产品级规则。交易所业务规则已明确的内容本文不再重复。

## 二、成交金额计算

### 2.1 单笔成交金额

单笔成交金额指一笔成交所产生的金额，按该笔成交的成交价格与成交数量的乘积计算。

计算以该笔成交为单位独立进行，不与其他成交合并计算。

### 2.2 成交金额精度

成交金额的计算结果需按产品定义的金额精度进行舍入处理，采用四舍五入方式。

**不同产品可配置不同的金额精度。**金额精度由产品参数定义，系统按下述两类精度分别支持：

- **精度 0.01**：计算结果保留 2 位小数，第 3 位小数参与舍入判断。
- **精度 0.001**：计算结果保留 3 位小数，第 4 位小数参与舍入判断。

产品的金额精度与其价格精度是**两个独立参数**，不要求一致。价格精度为 0.001 的产品，其金额精度可以是 0.01 或 0.001，由产品参数指定。

### 2.3 价格精度与有效范围

价格精度由产品参数定义，系统支持 0.001、0.01 等精度配置。申报价格与成交价格均须符合对应产品的价格精度。

价格的有效范围与成交数量的有效范围由产品参数定义，系统在申报与成交环节均需校验范围。

### 2.4 舍入边界处理

当计算结果恰好处于舍入临界位置时，按四舍五入规则处理：

- 待舍入位小于 5 时向下舍去。
- 待舍入位等于 5 时向上进位。
- 待舍入位大于 5 时向上进位。

临界位置包含多种情形，例如：精度 0.01 时第 3 位小数为 5，精度 0.001 时第 4 位小数为 5。

## 三、累计成交金额

### 3.1 累计口径

累计成交金额为当日该产品所有单笔成交金额的累加。

**累加按逐笔计算后进行**：每笔成交先按第二章规则计算出符合金额精度的单笔金额，再将各笔金额累加。

### 3.2 累计结果精度

累计结果的精度与单笔金额精度一致，由产品参数定义。

累加过程中不引入额外舍入，即逐笔金额确定后直接相加。

### 3.3 累计范围

累计范围为当日该产品在竞价交易时段内达成的全部成交。跨交易日的累计不纳入当日累计成交金额。

无成交时，累计成交金额为 0。

## 四、订单类型体系

### 4.1 分类原则

交易系统按**价格确定方式**对订单类型进行分类，分为限价类和市价类两大类别。

- **限价类**：投资者指定委托价格，成交价格不优于委托价格。
- **市价类**：投资者不指定委托价格，按市场当时的对手方价格成交。市价类下根据成交价格的确定方式还可细分为若干子类型。

### 4.2 市价类子类型

市价类订单按"以何种对手方价格成交"可细分，系统需支持按对手方最优价格、本方最优价格、市价转限价、市价即时成交剩余撤销等方式确定成交价格。

各子类型的适用场景由产品配置，交易所业务规则对市价申报的适用时段另有规定的，从其规定。

### 4.3 订单生命周期状态

订单在生命周期内可处于以下状态：

| 状态 | 含义 |
|---|---|
| 失败 | 订单未被交易系统接受，未进入撮合 |
| 未成交 | 订单已进入撮合但尚未产生任何成交 |
| 部分成交 | 订单已产生成交，但成交数量小于委托数量 |
| 全部成交 | 订单的委托数量已全部成交 |
| 已撤销 | 订单在成交完毕前被撤销 |

状态之间按业务逻辑单向流转，已撤销与全部成交为终态。

## 五、撤单处理

### 5.1 撤单的允许条件

撤单请求需同时满足以下条件方被受理：

1. 订单处于可撤销状态（未成交或部分成交）。
2. 撤单请求发生在允许撤单的时段内。交易所业务规则对特定竞价阶段禁止撤单的，从其规定。
3. 撤单指令经交易系统确认。

### 5.2 不同订单状态下的撤单处理

| 订单状态 | 撤单处理 |
|---|---|
| 失败 | 订单未进入撮合，无撤单对象 |
| 未成交 | 允许撤销，撤销后订单终止 |
| 部分成交 | 仅未成交部分可撤销，已成交部分不可撤销 |
| 全部成交 | 不允许撤销，订单已终结 |
| 已撤销 | 不允许重复撤销 |

### 5.3 撤单生效机制

撤单指令发出后，需经交易系统确认方为生效。未经确认的撤单请求不产生撤销效果。

撤单生效后，被撤销的委托对应的资金或证券应及时返还。

### 5.4 特殊场景

停牌期间、盘后固定价格交易时段等特殊场景下的撤单处理，按交易所业务规则或产品配置执行。

## 六、金额边界处理

### 6.1 精度边界

金额计算结果处于精度边界时，按第 2.4 节的舍入规则处理。

### 6.2 数值范围边界

价格与数量均须处于产品参数定义的有效范围内。超出范围的申报按无效申报处理。

### 6.3 品种差异

不同产品可配置不同的价格精度、金额精度与数量单位。系统按产品参数分别处理，不做统一假设。

以下内容本文档暂未明确，需业务方补充确认：

3. 累计成交金额的**展示精度**是否与计算精度一致。
4. 停牌、盘后固定价格交易等特殊场景下撤单的**具体处理规则**。
